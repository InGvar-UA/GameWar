# GameWar

Локальний двомовний сайт спільноти Call of Duty на PS5. Основна мова — українська (`/`), російська має окрему сторінку (`/ru/`). Відкрийте `index.html` у браузері. Для перегляду та публікації збірка і залежності не потрібні.

## Перед публікацією

1. Вставте постійне посилання-запрошення в `DISCORD_INVITE` у файлі `script.js`.
2. Завантажте файли в репозиторій GitHub та ввімкніть **Settings → Pages → Deploy from a branch → main / root**.
3. Після відв’язування домену від попереднього проєкту налаштуйте `gamewar.fun` у GitHub Pages і DNS.

## Пошук Google

- Кожна мова має власні заголовок, опис, канонічну адресу та посилання `hreflang`.
- `sitemap.xml` і канонічні адреси зараз налаштовані на GitHub Pages. Після перенесення домену перезберіть сторінки з `SITE_URL=https://gamewar.fun/`.
- Тексти відповідають на запити на кшталт «з ким пограти в Call of Duty на PS5», «знайти тімейтів Warzone», «найти команду для DMZ». Вони описують реальну функцію сайту — перехід у Discord, без обіцянки автоматичного підбору.
- Після перенесення домену оновіть канонічні адреси та sitemap на `https://gamewar.fun/`.
- Якщо редагуєте переклади в `script.js`, запустіть `build_locales.py`, щоб оновити обидві статичні сторінки. Скрипту потрібні Node.js та Python з `lxml`.

Поки посилання Discord не задане, кнопки показують пояснення замість порожнього переходу.
